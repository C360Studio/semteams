## Goals / Non-Goals

- **Goals:** Produce a stdlib-generated, contract-tested file-level SHA-256 + MIT manifest for all 21 absorbed units at `8b99efe9c66a`, and lock in `internal/` destinations, `ExecutorRegistry` DI, substrate/transitive adaptations, and `#406`'s trimmed `/graphql` contract.
- **Non-Goals:** Moving runtime code or changing `go.mod`, configs, schemas, or `ui/` on `main`; reviving parked dev packs (ADR-058); or inventing local generic durability ahead of `semengine#24`.

## Decisions

### D1. Package layout: `internal/` tree vs. module-root SemStreams mirror
- **Option A (Selected — all under `internal/`):** Map the 21 absorbed units to `internal/agentic` (contracts/payloads), `internal/agentic/{agentrun,milestone,vocab,looptoken,deliverylane,agentterminal,modelwire,modelwire/responses,loop,dispatch,model,tools,tools/executors,tools/runner}` (plus `loop/{internal/loopbucket,internal/looprequest,lessonmatch,prompt}`), `internal/persona`, and `internal/gateway/graphgateway`; exclude unreferenced `agentic/{identity,research}` and add `internal/agentic/looptoken/token_test.go`. Cost: import rewrites across `cmd/semteams/**` and absorbed files in `#404`/`#406`. Blast radius: `internal/` + `cmd/`. Forecloses: external Go modules importing SemTeams runtime packages (none exist; SemDev absorbs in-repo per ADR-061 §2).
- **Option B (Module-root mirror `agentic/...`, `processor/...`, `gateway/...`):** Cost: smaller internal path delta. Blast radius: exports 20+ top-level packages on `github.com/c360studio/semteams`. Forecloses: reshaping internal seams without public API churn.
- **Adopter seam:** Milestone 2 (`#404`, `#406`) lands every absorbed file at its `manifest.json` `destination_path`, writes `internal/agentic/LICENSE` verbatim from `8b99efe9c66a`, and keeps `agentic/{identity,research}` out; copying `agentic/research` without action fails compilation on unported `pkg/fusion`.

### D2. `ExecutorRegistry` injection after `component.Dependencies.ToolRegistry` removal (`semengine#29`)
- **Option A (Selected — explicit catalog closure DI):** Change `runtimecatalog.RegisterComponents(reg *component.Registry, tools *agentictools.ExecutorRegistry) error` (plus `RegisterSchemaComponents(reg)` passing `nil` for offline schema/OpenAPI generation) to bind `tools` via `RegisterWithExecutorRegistry(reg, tools)` on `agentic-tools` and `RegisterWithToolRegistry(reg, tools)` on `agentic-loop` and `agentic-dispatch` (narrow `ToolRegistryReader` interface in `internal/agentic`). Cost: 4 registration helpers + `cmd/semteams/main.go` reorder so `setupToolsAndPreprocessor` runs before catalog registration (or binds registry into catalog before `ConfigureFromServices`). Blast radius: `internal/runtimecatalog`, `cmd/semteams/main.go`, `cmd/openapi-generator`, 3 absorbed processors. Forecloses: mutating tool wiring after component construction.
- **Option B (Package-level global singleton):** Cost: 1 global var. Blast radius: shared mutable state across parallel `-race` tests. Forecloses: isolated per-test registries in parallel component tests.
- **Adopter seam:** Callers of `RegisterComponents` pass the constructed `*ExecutorRegistry` (or `RegisterSchemaComponents` for schema-only callers); passing `nil` in runtime boot leaves shared tools empty (`agentic-dispatch` resolves zero default tools and `agentic-loop`/`agentic-tools` reject unconfigured shared tool calls).

### D3. Substrate and transitive helper seams (`#77`/`#287`, `#25`–`#28`, `#32`/`#484`, `#69`/`#137`, ADR-113)
- **Option A (Selected — bind SemEngine contracts + `modelwire` + narrow `graph.mutation.>` helper):** (1) Rewrite `internal/lifecyclecleanup` -> `semengine/pkg/lifecyclecleanup.RollbackFailedStart` (non-nil callback required; `#77`), and give absorbed components + `MilestoneService` internal run contexts cancelled only by `Stop(ctx)` (ADR-113 `#361`; `milestone_health_test.go:42` switches from unexported `handleSystemHealth` to public HTTP/Service health). (2) Replace `graph/llm` in `internal/agentic/loop/{component.go,summarizer.go}` with `internal/agentic/modelwire.NewClient` + `semengine/model.NewHTTPClient` (matching `intent_classifier.go:106-135`, zero `go-openai`). (3) Replace `semstreams/internal/graphmutation` in `loop` and `tools` with `internal/agentic/graphmutation` (`InterfaceType = "semengine.graph.mutation"`, `SubjectFamily = "graph.mutation.>"`, single-attempt `RequestClassified` over `semengine/graph.{CreateEntityRequest,AppendTriplesRequest,EntityMutationResponse}` with ADR-110 `Source` + `Timestamp`). (4) Register `publish_agent` on `semengine/processor/rule` via `internal/agentic/rulefamily` (`E1`–`E4`, `#25`–`#28`, `#405`). Cost: ~180 LOC across 3 local adapters. Blast radius: `internal/agentic/{loop,tools,milestone,rulefamily}`. Forecloses: `go-openai` dependency in `loop`.
- **Option B (Vendor `graph/llm` + fork `internal/graphmutation` verbatim with `"semstreams.graph.mutation"`):** Cost: carries `go-openai` and mismatched port interface type. Blast radius: fails `semengine/composition.Validate` (`"semengine.graph.mutation"` check) and duplicates HTTP transport config. Forecloses: clean Tier-0 substrate closure.
- **Adopter seam:** Every absorbed triple write stamps non-empty `Source` and `Timestamp` (ADR-110) and declares port interface `"semengine.graph.mutation"`; omitting either fails `composition.Validate` at boot or refuses mutations as `invalid_request`.

### D4. Trimmed SemTeams GraphQL & trajectory gateway (`#406`)
- **Option A (Selected — `POST /graphql` over 4 queries, drop index/MCP/inference/status surfaces):** `internal/gateway/graphgateway` keeps factory/component name `"graph-gateway"` and mounts only `POST /graphql` via `RegisterHTTPHandlers`, declaring 2 output ports (`graph_queries` -> `graph.query.*`, `agentic_queries` -> `agentic.query.*`) and serving `trajectory`, `entitiesByPrefix`, `pathSearch`, and `entity` (unwrapping SemEngine's 4-key `graph.QueryResponse` envelope and mapping `ExactEntity.KVRevision` JSON `kv_revision` to GraphQL `kvRevision`). Drops `_ gateway.Gateway`, `globalSearch`/`searchGraph`, `/mcp`, `/inference/*`, `GRAPH_STATUS` readiness watcher, and bootstrap keys `graph_index_queries` + `mcp_path`; `#406` removes unreferenced `graphApi.globalSearch`, `ui/src/lib/server/ai/toolExecutors.ts`, and `ui/src/lib/server/graphql/client.ts`. Cost: ~70% gateway LOC reduction + dead UI test cleanup in `#406`. Blast radius: `internal/gateway/graphgateway`, bootstrap configs, dead UI client files, `specs/openapi.v3.yaml`. Forecloses: NLQ `globalSearch` until `graph-clustering` is intentionally composed.
- **Option B (Carry full `graph-gateway` + `globalSearch`):** Cost: requires composing `semengine/processor/graph-clustering` (`COMMUNITY_INDEX` writer) or serving `index_not_ready` errors, plus carrying unused MCP/anomaly routes. Blast radius: runtime memory/NATS footprint and OpenAPI surface. Forecloses: minimal 9-component runtime without clustering.
- **Adopter seam:** `#406` must delete `graph_index_queries` and `mcp_path` from both bootstrap JSON files in the same commit that swaps `graph-gateway`, or SemEngine `config`'s strict unknown-key and `composition.Validate` checks abort startup.

## Risks / Trade-offs

- **Upstream `E1`–`E4` / `#24` signature drift before `setup-04a-06` pins:** Mitigated by keeping `#404`–`#407` parked until `setup-04a-06`, `#24`, and `#361` land, and isolating `publish_agent` glue in `internal/agentic/rulefamily` (`#405`).
- **`kv_revision` / `QueryResponse` wire mismatch:** Mitigated by explicit contract tests in `#406` covering `ExactEntity.kvRevision` and `QueryResponse` unwrap against live `semengine/processor/graph-query`.
