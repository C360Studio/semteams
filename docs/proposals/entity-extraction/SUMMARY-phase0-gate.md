  - **Day-one portfolio-only catalog (`8` C360/NATS entries, zero third-party entities seeded):** `T0` suppresses `6/6` B4 unmentioned claims plus `1/6` B2 (`b2-02`, false suppression), leaving `29/36` claims that pass `checkMention`. `T0/T1` resolves `12/29` (`10` C360/NATS portfolio hits across B1/B5 + `2` non-portfolio ID-pattern hits `RFC 9110` and `München-Lab/quantum-sim`), leaving **`17/36` (`47.2%`) residual `type`/`link` model calls (`52.8%` call reduction)**.   - Because the 12 `unstated_gloss` claims relabeled `expect.support = false` in `corpus_v1.json` were selected post-hoc from the mentioned, non-contradicted rows where Mercury forward scored `p_yes < 0.60`, `StrictSupp` is retained only to show that two-sided strict role entailment rejects valid entities with background gloss, not to compare backends.

- **`Arm 1` (`eval_algo_t0_t1.json`):** `T0/T1` algorithm floor alone across `Warm` (`23` entities authored from this corpus's gold links), `Port` (`8` day-one C360/NATS portfolio entities), and `Empty` (`0` seeded entities).
