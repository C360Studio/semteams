# Retired flow templates

These files are historical donor material. The frozen SemStreams upgrade retires
flow-template storage, rendering tools, loader code, and the `--flow-templates`
flag. SemTeams no longer loads this directory or creates `FLOW_TEMPLATES`.

The shipped runtime remains one bootstrap composition with category rule packs.
Author those configuration files and restart; no saved-flow authoring service or
compatibility route is provided. See the [migration inventory](../../docs/migrations/semstreams-8b99efe/contract-inventory.md).
